The IDD Tools Landscape

Infectious disease dynamics runs on software. This is a curated, evidence-checked index of that software: the tools themselves, the ecosystems built so that tools work together, and the communities that build and maintain them. Inclusion is not an endorsement by GSIDD. To suggest an addition or a correction, write to info@gsidd.org.

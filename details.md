# Infections Disease Dynamics Software Tools

## **Background**

This repository stores the data underlying the "IDD tools" section of the Global Society for Infectious Disease Dynamics ([gsidd.org](http://gsidd.org)) website.

This section lists software packages and tools of use or interest to the IDD community. The aim of this section is to:

1. Create and enhance **communities of practice** for IDD software tools, by:  
   1. Bringing together researchers who are working with similar methods and/or on similar problems, to share ideas and solutions;  
   2. Connecting beginning users with experienced users and tool developers, for help, support, and mentorship;  
   3. Connecting tool developers with each other, to share best practices and community standards.  
2. **Improve visibility of software tools**, to encourage reuse:  
   1. Provide a platform for highly developed software tools to become more widely known and used;  
   2. Provide a pathway for high-quality new tools to become integrated into and used by the IDD community.

## **Definitions**

The following types of software tools will be eligible to be included:

* **Models**: IDD models of all types (e.g. analytical, statistical, or computational); for any disease (e.g. respiratory, vector-borne, NTDs, STIs); at any scale (e.g. between host, between communities, between species, or within-host); and in any discipline (e.g. epidemiology, public health, math/stats, comp sci, ecology, immunology).  
* **Utilities**: IDD-related tools for solving particular problems (e.g. loading and processing data, performing statistical analyses).  
* **AI extensions:** AI-based agents, skills, and plugins for performing IDD tasks.

## **Criteria for inclusion**

* The tool is **open source** on GitHub or equivalent, and has an open-source license (e.g. MIT, Apache, Creative Commons).  
* The tool has been **published** in e.g. a scientific journal, a software journal like JOSS, a preprint server like arXiv, etc.  
* The tool is **documented**, with minimum requirements including installation instructions, a getting started guide with at least one example/vignette, and a technical reference guide describing tool features.  
* The tool has **evidence of use**, e.g. the tool is available on CRAN or PyPI, has a significant number of GitHub stars or forks, and/or has been used for multiple publications.  
* The tool is **supported**, with development activity within the last 3 years (and ideally, commitment from the maintainers of at least 12 months of additional support).

The following do **not** meet the inclusion criteria:

* General-purpose tools that are used for, but not unique to, IDD (e.g. tidyverse, pandas, UNPop).  
* Software tools that have not been used except by the tool's author or immediate research group.
* Information about or guidance on software tools (e.g. training guides), rather than the tools themselves.
* Data and databases (these would potentially be in a separate section).

## **Tool communities**

This section lists existing communities that have been involved in developing, using, hosting, or curating IDD tools. Examples include:

* WHO-Collaboratory  
* MIDAS  
* Vaccine Impact Modelling Consortium  
* HIV Modelling Consortium  
* NTD Modelling Consortium  
* MRC Centre for Global Infectious Disease Analysis (UK)  
* Institute for Disease Modeling (USA)  
* Epistorm (USA)

* EpiModel  
* Epistorm  
* Starsim

## **Tool database**

Each software tool is listed in a table with the following metadata:

* Name  
* Type (i.e. model, utility, AI extension)  
* Discipline (epidemiology, global health, math & stats, etc.)  
* Pathogen (respiratory, vector-borne, NTDs, etc.)  
* Language (R, Python, etc.)  
* Description
* Authors  
* Link to code
* Link to publication (if available)

# Disease modeling tool web presence

This file lists the tools from the [main summary](../README.md) in reference to their web presence: what kind of URL each tool uses, and what a first-time visitor finds there.

**Scope and caveats:** this table describes the *format and completeness of each project's landing page only*. It is not an assessment of the quality, correctness, or usefulness of the software, and a documentation-generator default page is a reasonable choice for many projects. Categories are applied uniformly, including to the author's own tools. Assessments are a snapshot as of 2026-08-07 and will drift as sites are updated.

**URL type**: *Custom* = dedicated domain for the tool; *Semi-custom* = dedicated project site on a shared/hosted domain; *Org* = page within the parent organization's website; *Default* = the default URL provided by a docs host (Read the Docs, GitHub Pages, pkgdown).

**Site content**: *Full landing page* = purpose-built site with orientation, examples, and navigation beyond the API docs; *Minimal landing page* = a short description and links; *Docs default* = the unmodified output of a documentation generator.

Tools are listed alphabetically. Usage metrics and status are carried over from the [main summary](../README.md); stars are as of 2026-08-07 and download counts as of 2026-05-06.
